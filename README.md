# Magic Ebook

A web platform for creating and selling e-books online.

🌐 **Live demo:** https://magic-ebook-site.vercel.app

## About

Magic Ebook allows creators to publish e-books, create sales pages and receive payments through PIX or credit card.

## Features

- E-book publishing
- Sales pages
- Mercado Pago integration
- PIX and credit card payments
- Responsive interface
- Rich text editor
- Form validation

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod
- TipTap
- Radix UI
- Mercado Pago SDK

## Getting Started

```bash
git clone https://github.com/carvalho-rafael/magic-ebook-site.git

cd magic-ebook-site

npm install

npm run dev
```

Open `http://localhost:3000`.
